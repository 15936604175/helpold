# 互助SOS Demo - 产品需求文档

## 1. 产品概述
基于现有 Flutter 项目「互助SOS-社区紧急求助平台」创建网页端 Demo，用于展示项目的核心功能和使用方式。Demo 以手机模拟器样式呈现，支持三种角色一键切换，使用虚拟数据展示完整业务流程。
- 目标用户：项目展示受众（投资者、开发者、测试人员）
- 核心价值：直观展示三种角色的核心交互流程，无需安装 APP 即可体验

## 2. 核心功能

### 2.1 用户角色
| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 求助者 | 老年/残障人士 | 发起SOS求助、查看求助状态、追踪确认 |
| 帮助者 | 互助志愿者 | 在线状态切换、查看附近求助、接单、位置计划管理 |
| 紧急联系人 | 家属/监护人 | 发起位置追踪、查看患者位置、电子围栏配置 |

### 2.2 功能模块
1. **角色切换面板**：网页顶部三个角色按钮，点击即时切换手机内界面
2. **求助者模式**：SOS大按钮、3秒倒计时确认、求助原因选择、求助中等待页、追踪状态栏
3. **帮助者模式**：在线/离线/忙碌状态切换、当前匹配位置、附近求助列表、接单详情、位置计划管理
4. **监护人模式**：患者列表、追踪请求、追踪历史、电子围栏配置
5. **设置页**：个人信息、模式切换、关于信息

## 3. 核心流程

### 求助者发起求助流程
1. 点击SOS按钮 → 3秒倒计时确认 → 选择求助原因 → 发送求助
2. 进入求助中页面 → 等待帮助者接单 → 接单成功显示帮助者信息

### 帮助者接单流程
1. 收到求助通知 → 查看附近求助列表 → 点击查看详情 → 确认接单

### 监护人追踪流程
1. 查看患者列表 → 发起位置追踪 → 患者确认 → 显示位置

## 4. 用户界面设计

### 4.1 设计风格
- 主色：琥珀色 #FFA000（与Flutter APP一致）
- SOS红：#D32F2F
- 成功色：#4CAF50 / 警告色：#FF9800 / 错误色：#E53935
- 背景：#FAFAFA
- 卡片：白色圆角12px
- 字体：系统字体栈，标题16-20px，正文13-14px
- 布局：手机模拟器居中，顶部角色切换栏

### 4.2 页面设计概览
| 页面 | 布局风格 | 关键元素 |
|------|----------|----------|
| 角色切换栏 | 顶部水平排列 | 三角色按钮+高亮选中态 |
| 手机框架 | 居中375x812px | 圆角边框+刘海+状态栏 |
| SOS主页 | 居中垂直 | 巨大圆形红色按钮+信息卡片 |
| 求助列表 | 垂直卡片流 | 求助卡片+距离标签 |
| 监护面板 | 垂直卡片流 | 患者卡片+追踪按钮 |

### 4.3 响应式
- 桌面端：手机框架居中，两侧留白展示说明
- 移动端：手机框架占满屏幕
